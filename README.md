# Hiro Stash

Kho ý tưởng cá nhân kiểu Deepstash: ghi lại các ý tưởng ngắn từ sách/bài viết, gắn chủ đề, tìm kiếm, đánh dấu yêu thích và ôn ngẫu nhiên.

Chạy: mở `index.html` trong trình duyệt, hoặc `python3 -m http.server` rồi vào http://localhost:8000.
Dữ liệu lưu trong localStorage của trình duyệt; dùng "Xuất JSON" để sao lưu / chuyển máy.
